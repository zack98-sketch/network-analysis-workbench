# 用户操作手册

本文档是网络环境分析工作台的完整用户手册，涵盖各模块功能说明、典型工作流、快捷键和常见问题。

---

## 登录

工作台采用**无密码模式**，无需注册登录。

- 首次访问时系统自动初始化并创建一个**默认项目**（`default`）
- 所有数据存储在本地，不上传任何云端
- 如需隔离不同审计任务，可在「项目中心」新建多个项目

---

## 模块说明

### 1. 总览（Dashboard）

**功能描述**：总览页以仪表盘形式展示当前项目的整体状态，包括上传文件数量、解析进度、风险分布、告警趋势和关键统计指标。帮助用户快速把握项目全貌，识别需要关注的高风险项。

**关键操作**：
1. 顶部卡片展示上传文件数、已识别设备数、风险项总数、待整改数四个核心指标
2. 风险等级饼图直观呈现严重/高危/中危/低危/信息的比例，点击任意扇区可跳转至对应风险清单
3. 时间趋势折线图展示最近 7/30 天的告警数量变化，用于发现异常波动

### 2. 文件上传（Materials）

**功能描述**：文件上传模块负责导入原始审计材料，包括设备日志、配置文件和产品手册。支持拖拽上传、批量上传、断点续传；上传后自动触发格式识别和后台解析队列，用户可实时查看进度。

**关键操作**：
1. 点击「选择文件」或直接拖拽文件到虚线框区域，支持一次选择多个文件
2. 上传列表显示每个文件的进度条、大小、状态（等待/上传中/解析中/完成/失败）
3. 上传完成后点击「解析详情」查看该文件识别出的设备、记录条数和解析耗时

### 3. 日志关联（Log Analysis）

**功能描述**：日志关联模块对上传的防火墙/IDS/交换机等设备日志进行归一化解析、时间轴对齐和关联分析，自动识别攻击事件、流量异常和策略命中情况。支持按源/目的 IP、端口、动作、时间范围多维度过滤。

**关键操作**：
1. 左侧筛选面板选择设备、日志类型、动作（允许/拒绝）、时间范围，点击「查询」
2. 结果列表中点击单条日志展开关联视图，查看同一会话相关的所有日志条目
3. 切换到「统计」子页，查看 Top N 攻击源、被攻击端口排名、策略命中等可视化图表

### 4. 配置解析（Config Parser）

**功能描述**：配置解析模块将网络设备（防火墙、路由器、交换机）的 `.cfg` / `.conf` 配置文件解析为结构化模型，包括接口、ACL 规则、NAT、VPN、安全策略等对象。支持语法高亮、树状浏览、配置版本对比。

**关键操作**：
1. 在设备下拉列表选择已解析的设备，页面左侧显示配置分类树（接口/ACL/NAT/策略）
2. 点击分类节点在右侧查看具体配置项，关键字段以高亮显示并附带安全合规提示
3. 点击顶部「版本对比」下拉选择两个版本，进入 Diff 视图高亮显示新增/删除/修改行

### 5. 风险分析（Risk Assessment）

**功能描述**：风险分析模块基于内置规则引擎和 CIS/等保基线自动扫描配置和日志中的安全隐患，生成包含风险等级、影响范围、整改建议的风险清单。风险项支持手动确认、标记误报、分配处理状态。

**关键操作**：
1. 点击「重新扫描」触发全量风险检测（新增配置或规则后），进度条实时更新
2. 使用筛选器按风险等级（严重/高/中/低/信息）、类别（ACL/NAT/口令/日志等）过滤
3. 点击单条风险查看详情：问题描述、证据片段、CVE/标准引用、推荐整改命令

### 6. 拓扑视图（Topology）

**功能描述**：拓扑视图模块根据配置文件中的接口、路由、VPN 和 ARP 信息自动推导网络拓扑，以可交互的力导向图展示设备、子网、链路及其属性。支持手动调整节点位置并保存布局。

**关键操作**：
1. 打开拓扑页等待自动生成，节点按设备类型（防火墙/交换机/路由器）使用不同图标
2. 鼠标拖拽节点调整位置，滚轮缩放画布，悬停节点显示接口和 IP 信息
3. 点击链路高亮并查看该链路所属 VPN / 安全域信息，右键菜单可导出单节点配置

### 7. 手册检索（Docs Search）

**功能描述**：手册检索模块将上传的 `.chm` / `.pdf` / `.html` / `.md` 产品文档建立全文索引，支持自然语言搜索、关键词高亮和上下文片段展示。帮助用户快速查找命令手册、故障排查步骤和功能说明。

**关键操作**：
1. 首次上传手册后点击「建立索引」，等待进度完成（CHM 解压 + 分词，大文档可能需要数分钟）
2. 在搜索框输入查询词（如「端口映射配置」「NAT Server 命令」），回车搜索
3. 结果列表点击条目打开文档阅读器，关键词高亮定位，侧边栏显示文档目录结构

### 8. 规则引擎（Rules Engine）

**功能描述**：规则引擎模块管理风险检测所使用的规则集，支持查看内置规则、启用/禁用单条规则、导入自定义 YAML 规则、调整规则权重和匹配条件。适合高级审计人员根据现场环境定制检测逻辑。

**关键操作**：
1. 浏览规则列表，通过开关启用或禁用指定规则，搜索框支持按规则 ID/名称/类别过滤
2. 点击「新建规则」填写规则元数据、匹配逻辑（支持逻辑运算和正则）、风险等级和整改建议
3. 使用「导入」功能批量上传 YAML 格式的自定义规则包，导入后自动生效

### 9. 项目中心（Projects）

**功能描述**：项目中心用于管理多个独立的审计项目，每个项目拥有独立的文件、解析结果、风险记录和导出报告。支持新建、重命名、归档、删除项目，以及在项目间切换上下文。

**关键操作**：
1. 点击「新建项目」输入名称和描述（可选），创建后自动切换到新项目
2. 项目列表显示每个项目的创建时间、文件数、风险数、大小，点击行切换当前项目
3. 使用「归档」功能将已完成的项目压缩为单个备份包，「导入」恢复历史归档

### 10. 报告导出（Reports）

**功能描述**：报告导出模块将项目中的关键信息汇总为标准化审计报告，支持 PDF / Word / Markdown / HTML 四种格式。用户可选择报告模板、包含的章节、Logo 和封面信息，导出后可下载或在线预览。

**关键操作**：
1. 选择报告格式（PDF/Word/Markdown/HTML）和模板（标准/精简/详细）
2. 勾选需要包含的章节：项目信息、设备清单、配置摘要、风险清单、整改建议、附录等
3. 点击「生成报告」等待进度完成，PDF 报告首次生成需启动 Chromium，约 30-60 秒

## 典型工作流（5 步法）

### 第 1 步：新建项目

进入「项目中心」→ 点击「新建项目」→ 输入项目名称（如「XX 分行网络季度审计」）和备注 → 确定后自动切换到新项目。

### 第 2 步：上传日志 + 配置 + 手册

进入「文件上传」→ 拖拽或选择待审计的文件：
- 日志：`*.log`, `*.csv`, `*.txt`
- 配置：`*.cfg`, `*.conf`, `*.txt`
- 手册/文档：`*.chm`, `*.pdf`, `*.html`, `*.htm`, `*.md`

上传完成后系统自动排队解析，观察进度条直至全部显示「完成」。

### 第 3 步：等待自动解析 + 风险检测

- 切换到「配置解析」确认设备配置已正确拆解
- 切换到「日志关联」确认日志已正确入库
- 切换到「风险分析」点击「重新扫描」触发全量规则检测

### 第 4 步：查看风险清单和整改建议

- 在「风险分析」中按严重程度从高到低逐条审查
- 对确认无误报的风险标记为「待整改」
- 对误报的风险标记为「已忽略」并填写原因
- 必要时跳转到「手册检索」查阅相关命令参考

### 第 5 步：生成并导出报告

- 进入「报告导出」→ 选择格式（推荐 PDF）和「详细」模板
- 勾选「风险清单（含整改建议）」「配置对比」「拓扑图」等章节
- 点击「生成报告」→ 等待完成后点击「下载」保存到本地

## 快捷键

| 快捷键 | 功能 | 适用场景 |
|--------|------|----------|
| `⌘K` / `Ctrl+K` | 全局搜索 | 任意页面唤起全局搜索框，搜索菜单、设备、风险项、文档 |
| `Esc` | 关闭弹窗 / 取消搜索 | 模态框或搜索框打开时 |
| `⌘S` / `Ctrl+S` | 保存当前编辑 | 规则编辑、项目备注编辑等场景 |
| `⌘E` / `Ctrl+E` | 导出当前视图 | 列表页导出 CSV / 拓扑页导出 PNG |
| `←` / `→` | 翻页 / 切换版本 | 配置对比 Diff 视图 |
| `/` | 聚焦当前页搜索框 | 列表页、手册检索页 |

## 支持的文件格式

### 日志类（日志关联模块）

| 扩展名 | 说明 | 推荐编码 |
|--------|------|----------|
| `.log` | 原始设备日志（Syslog / 本地导出） | UTF-8，GBK 自动尝试转换 |

| 扩展名 | 说明 | 常见来源 |
|--------|------|----------|
| `.cfg` | 设备配置文件 | 华为 VRP `display saved-configuration` 导出 |
| `.conf` | 通用配置文件 | 开源设备/服务配置 |
| `.txt` | 纯文本配置 | 命令行回显拷贝 |

### 手册 / 文档类（手册检索模块）

| 扩展名 | 说明 | 常见来源 |
|--------|------|----------|
| `.chm` | 微软编译 HTML 帮助 | 华为官方产品文档 CHM |
| `.pdf` | 便携式文档格式 | 培训教材、实验手册 |
| `.html` / `.htm` | 网页文档 | 在线文档归档 |
| `.md` | Markdown 文档 | 内部文档、知识库 |

## 版本对比（配置 Diff）

上传同一设备的多个配置版本后，可进行配置差异对比：

1. 进入「配置解析」页面
2. 在顶部设备下拉列表选择目标设备
3. 点击「版本对比」按钮
4. 在弹出的选择框中分别选择 **基准版本**（旧）和 **对比版本**（新）
5. 点击「对比」进入 Diff 视图：
   - 🟢 绿色背景行 = 新增配置
   - 🔴 红色背景行 = 删除配置
   - 🟡 黄色高亮字符 = 修改的内容差异
6. 右上角可切换「按分类分组」或「按时间线性」视图

> **提示**：建议在变更窗口前后分别导出配置并上传，通过 Diff 快速定位本次变更内容，辅助排查变更引入的风险。

## 常见问题（FAQ）

### Q1. 为什么文件解析失败？

**可能原因与排查**：
1. **文件编码不支持**：尝试用文本编辑器（如 VS Code）将文件另存为 UTF-8 编码后重新上传
2. **文件格式不匹配**：确认文件后缀和实际内容一致，例如将 `.cfg` 改为 `.txt` 的纯日志会导致配置解析失败
3. **文件损坏**：特别注意 CHM 文件，需完整拷贝（未截断），可尝试在 Windows 下双击打开验证
4. **大小超出限制**：单文件上限 500 MB（Nginx 默认），超大日志建议分片压缩后上传
5. 查看「文件上传 → 解析详情 → 错误日志」获取具体报错信息

### Q2. 如何导入自定义检测规则？

1. 进入「规则引擎」模块
2. 点击右上角「导入」按钮
3. 选择符合格式的 YAML 规则包文件
4. 预览待导入的规则列表，确认后点击「确认导入」
5. 导入后的规则默认启用，可在列表中调整

**自定义规则 YAML 格式示例**：

```yaml
rules:
  - id: CUSTOM-001
    name: 默认放行所有出站流量
    category: ACL
    severity: high
    description: 检测 ACL 中存在 permit ip any any 的过于宽松规则
    match:
      type: regex
      pattern: 'rule\s+\d+\s+permit\s+ip\s+source\s+any\s+destination\s+any'
    suggestion: 收紧出站策略，按业务需要逐条放行目的地址和端口
```

### Q3. PDF 报告导出失败怎么办？

PDF 报告依赖内置的 Chromium（无头浏览器）进行渲染。

**Docker 部署**：镜像已预装所有 Chromium 运行库，一般不会失败。若失败：
1. 查看容器日志：`docker compose logs workbench | grep -i chromium`
2. 确保宿主机 `/tmp` 有可写权限（无头浏览器需要临时目录）

**源码部署**：
1. 确认系统依赖已安装：`libnss3 libatk1.0-0 libcups2 libdrm2 libgbm1 libasound2` 等（参见 Dockerfile 完整列表）
2. 确认中文字体：`apt install fonts-noto-cjk && fc-cache -fv`
3. 开发环境可临时切换为 HTML / Markdown 格式导出

### Q4. 手动上传文件到 data/uploads 后如何被系统识别？

直接拷贝文件到 `data/uploads/` 后，需要调用扫描 API 入库：

```bash
curl -X POST http://localhost:8080/api/v1/materials/scan \
     -H "Content-Type: application/json" \
     -d '{"project_id": "default", "recursive": true}'
```

参数 `recursive: true` 会递归扫描 uploads 子目录。

### Q5. 全文检索搜不到想要的内容？

1. 确认文档索引已建立：手册检索页右上角显示「索引状态：已就绪」
2. 若文档是新上传的，点击「重建索引」（全量）或「增量更新」
3. 搜索关键词使用中文或英文单词，避免长句子；多个关键词用空格分隔表示 AND
4. CHM 文档需要解压，首次索引时「手册检索 → 索引状态」会显示进度，待完成后再搜索

### Q6. 风险分析误报太多，如何调整？

三种方式，按推荐程度：

1. **禁用不适配的规则**：在「规则引擎」中搜索对应规则 ID，关闭开关
2. **降低规则权重**：编辑规则，将 `severity` 从 `high` 调低为 `medium` 或 `low`
3. **单条忽略**：在「风险分析」中选择误报的条目，批量标记为「已忽略」并填入忽略理由，后续重新扫描时不会再次生成该组合

### Q7. 数据如何完全重置（清空所有项目）？

**⚠️ 操作不可逆，请先备份**

```bash
# Docker 部署
cd deploy
docker compose down
rm -rf data/*
docker compose up -d

# 源码部署
cd backend
rm -rf data/uploads/* data/exports/* data/index/* data/workbench.db
# 重启 uvicorn 进程
```
